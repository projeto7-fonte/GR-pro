# SeuTon

**SUA MÚSICA. SEU TOM. SEU JEITO DE TOCAR.**

Aplicativo de cifras e acompanhamento musical.

## Visão inicial

O SeuTon será construído como uma plataforma para músicos encontrarem, organizarem e tocarem músicas com cifras de forma simples.

### Primeira fase

- Catálogo de músicas e cifras
- Busca por música, artista e tom
- Transposição de tonalidade
- Exibição de acordes e cifras
- Controle de tom e andamento
- Favoritos
- Interface responsiva para celular

### Direção técnica

A base do projeto será preparada para uma aplicação web moderna, com TypeScript e uma arquitetura que permita adicionar autenticação, banco de dados e recursos musicais progressivamente.

## Identidade

O nome oficial do produto é **SeuTon**. A identidade visual definida utiliza símbolo musical em formato de S com cordas, preto/branco e destaque dourado/laranja, com a assinatura:

> SUA MÚSICA. SEU TOM. SEU JEITO DE TOCAR.
